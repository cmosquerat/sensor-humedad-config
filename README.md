# Sensor de humedad · configuración

App web para configurar por **Bluetooth** el sensor de humedad (ESP32-C6) y ver sus lecturas guardadas.

**Abrir:** https://cmosquerat.github.io/sensor-humedad-config/

- Funciona en **Chrome** (Android, PC, Mac). No funciona en iPhone, porque Safari no soporta Web Bluetooth.
- Pulsa **WAKE** en el sensor, abre la página y toca **Conectar sensor**.
- Después de la primera visita funciona sin internet y se puede instalar como app.
- **Probar sin sensor** abre una demostración con datos simulados.
